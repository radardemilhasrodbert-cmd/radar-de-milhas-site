O que é o Radar de Milhas

É uma ferramenta pessoal, usada por uma única pessoa, o próprio dono. Ela reúne promoções de passagens e de milhas saindo do Rio de Janeiro. Não é uma empresa, não vende nada e não tem outros usuários.

Quais dados do Google o app usa

  • O app usa apenas uma conta Gmail: radardemilhasrodbert@gmail.com. O dono criou essa conta só para o radar.
  • Essa caixa recebe e-mails de programas de fidelidade (como Smiles, LATAM Pass, Azul Fidelidade, TAP Miles&Go, Livelo e C6). O próprio dono encaminha esses e-mails da conta pessoal dele.
  • Leitura (permissão gmail.readonly): o app lê esses e-mails para encontrar promoções. Nenhum e-mail é alterado ou apagado.
  • Envio (permissão gmail.send): o app envia um resumo diário, e só para o e-mail pessoal do dono.

Para onde vão os dados

  • O app guarda trechos das promoções (assunto, data, link e o texto da oferta) num banco de dados do próprio dono.
  • O radar roda em horários programados, no computador do dono ou num serviço de automação contratado por ele, sempre em ambiente privado.
  • Para resumir e organizar as ofertas, trechos desses textos são enviados à API da Anthropic (Claude).
  • O resultado, ou seja, as promoções já organizadas, aparece num painel com acesso restrito ao dono (Cloudflare) e nos avisos do Telegram do dono.

O que o app não faz

  • Não vende os dados e não os compartilha com terceiros além dos serviços citados acima, que são usados só para o radar funcionar.
  • Não usa os dados para publicidade e não os usa para treinar modelos de inteligência artificial.
  • Não pede senhas, não acessa outras contas do dono, não transfere pontos e não compra passagens.

Como revogar o acesso

Para remover o acesso, abra myaccount.google.com/permissions, escolha Radar de Milhas e clique em remover. A partir daí, o app não consegue mais ler nem enviar e-mails. O banco de dados é do dono, que pode apagá-lo quando quiser.

Política de Dados do Usuário do Google

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google pelo Radar de Milhas seguem a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado.
